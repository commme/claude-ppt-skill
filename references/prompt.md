## PPT 생성 프롬프트

```text
너는 10년차 발표자료 기획자이자 PPT 디자이너다.

아래 기획안과 디자인 기준을 바탕으로 발표자료를 만들어줘.

주제:
[주제]

목적:
[발표용 / 제출용 / 제안서 / 교육자료 / 보고자료 / 소개서]

청중:
[임원 / 고객 / 투자자 / 학습자 / 내부팀 / 심사위원]

핵심 메시지:
[발표 후 기억해야 할 한 문장]

스토리라인:
[문제→해결 / 개념→실습 / Before→After / 기타]

디자인 스타일:
[P01 미니멀 B2B SaaS / P02 따뜻한 교육자료 / P03 절제된 금융 보고서 /
 P04 스타트업 IR / P05 감성 브랜드 소개서 / P06 AI/IT 강의자료 /
 P07 모던 다크 컨트라스트 / P08 에디토리얼 매거진 / P09 웰니스 친화 /
 P10 카드뉴스 스타일 / P11 핀테크 클린 / P12 와비사비 미니멀 /
 P13 모바일 앱 출시 / P14 럭셔리 블랙 / P15 이커머스 활기 /
 P16 비영리/공익 / P17 건축/부동산 / P18 데이터 시각화 /
 P19 한국 트렌디 / P20 어린이 교육 동심]

컬러:
[HEX 코드 팔레트]

폰트:
[제목 / 본문 / 숫자용 폰트 기준]

레퍼런스:
첨부한 레퍼런스는 그대로 복제하지 말고,
여백감, 제목 위치, 카드형 정보 배치, 색감, 아이콘 스타일만 참고해줘.
문구와 내용 구성은 새 자료에 맞게 다시 작성해줘.

슬라이드 구성:
[슬라이드별 내용]

금기사항:
- 과한 그라데이션 금지
- 의미 없는 아이콘 남발 금지
- 제목 아래 의미 없는 가로선 금지
- 본문 임의 왜곡 금지
- 텍스트 넘침 금지

각 슬라이드에는 제목, 핵심 메시지, 본문, 시각 구조, 발표자 메모를 포함해줘.
```

## 레퍼런스 적용 프롬프트

```text
첨부한 레퍼런스는 그대로 복제하지 말고,
여백감, 제목 크기와 위치, 카드형 정보 배치, 색감, 아이콘 스타일만 참고해줘.

문구와 내용 구성은 새 자료의 목적과 청중에 맞게 다시 작성해줘.

참고할 것:
1. 여백감
2. 제목 크기와 위치
3. 카드형 정보 배치
4. 색감과 톤
5. 아이콘 스타일
6. 그래프/표의 단순화 방식

복제하지 않을 것:
1. 문장 구조
2. 이미지 구성
3. 브랜드 요소
4. 세부 레이아웃
5. 고유 문구
```
